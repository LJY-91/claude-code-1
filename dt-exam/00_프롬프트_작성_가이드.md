# AI에게 시험문제를 잘 만들게 하는 프롬프트 작성법

"문제 만들어줘"처럼 짧게 요청하면 평범한 문제가 나옵니다. 아래 6가지만 지키면 결과가 크게 좋아집니다.

## 1. 핵심 원칙 6가지

| # | 원칙 | 나쁜 예 | 좋은 예 |
|:-:|---|---|---|
| 1 | **목표와 용도** | "금융DT 문제 만들어줘" | "금융DT 14회(2026.11) DT-Blue(80점 이상) 등급을 목표로 한 모의고사를 만들어줘" |
| 2 | **자료 첨부 + 활용법** | (자료 없이 요청) | "첨부한 기출 PDF의 **출제 스타일**을 참고하되, 내용은 최신으로 **변형**해줘" |
| 3 | **범위/기준 명시** | "최신 내용으로" | "교재 6판 기준, 2026년 11월 현재 시행 중인 법·제도 기준" |
| 4 | **수량·난이도·유형** | "여러 문제" | "3과목 30문항, 상 30%·중 50%·하 20%, 가나다라 조합형 20%" |
| 5 | **출력 형식 고정** | "알아서 정리해줘" | "문제 → 4지선다 → 정답표 → 해설(1~2줄, 틀린 보기가 왜 틀렸는지)" |
| 6 | **검증과 불확실성 표시** | (없음) | "확실하지 않은 사실은 `[확인 필요]`로 표시하고, 근거가 약하면 문제에서 빼줘" |

## 2. 이번 작업에 적용한 프롬프트 (Before → After)

**Before (실제 요청)**
> 예전에 출제된 문제들을 토대로 요즘 시험문제에 맞게 변경해서 문제들을 제공해줘

**After (같은 내용을 더 정확히 요청하는 방법)**
```text
[역할] 너는 한국금융연수원 금융DT 테스트 출제위원이야.
[목표] 14회(2026.11) 대비 모의고사를 만들어줘. 교재는 6판 기준이야.
[자료] 첨부한 기출/예상문제 PDF는 "출제 스타일과 주제 범위"의 참고용이야.
       문장을 그대로 베끼지 말고, 개념은 유지하되 사례·수치·보기를 바꿔서 변형해줘.
[최신화] 원본에 오래된 내용(예: 시행 예정이던 법, 중단된 서비스)이 있으면
         현재 기준으로 고치고, 고친 부분은 해설에 "(갱신)"이라고 적어줘.
[구성] 1과목 15문항 / 2과목 15문항 / 3과목 30문항 / 4과목 15문항
[유형] 4지선다. "옳은 것 / 옳지 않은 것", 가나다라 조합형, 표 비교형, 사례 적용형을 섞어줘.
       지문은 길게, 틀린 보기에는 "그럴듯한 함정"을 넣어줘.
[정답] 정답 위치(①~④)가 한쪽으로 쏠리지 않게 해줘.
[해설] 정답 근거 1~2줄 + 원본 문제 번호(어떤 문제를 변형했는지).
[주의] 확실하지 않은 사실은 [확인 필요]로 표시하고, 지어내지 마.
[형식] 과목별 Markdown 파일로 작성하고, 맨 아래에 정답표를 둬줘.
```

## 3. 복사해서 쓰는 템플릿

```text
[목표]   (예: 14회 금융DT 80점 이상, DT-Blue 등급)
[자료]   (첨부 파일명) — 활용법: (스타일 참고 / 내용 변형 / 그대로 사용 금지)
[범위]   (교재·판수·기준 시점)
[구성]   (과목별 문항 수, 난이도 비율, 유형 비율)
[스타일] (지문 길이, 함정 방식, 말투)
[출력]   (파일 형식, 순서: 문제 → 정답표 → 해설)
[검증]   (불확실하면 표시, 근거 없는 내용 금지, 정답 분포 균형)
```

## 4. 결과가 아쉬울 때 쓰는 후속 프롬프트

한 번에 완벽하게 만들려 하지 말고 **대화로 다듬는 것**이 가장 효과적입니다.

| 상황 | 이렇게 요청 |
|---|---|
| 더 어렵게 | "3과목 블록체인만 10문항 더. 보기 4개가 모두 비슷해 보이는 **상 난이도**로" |
| 약점 보강 | "내가 틀린 번호는 2-7, 3-12, 3-25야. 같은 개념을 **다른 사례로 3문항씩** 더 만들어줘" |
| 해설 개선 | "해설을 **고등학생도 이해할 말**로, 외우기 쉬운 연상법도 한 줄 넣어줘" |
| 신뢰도 확인 | "방금 문제 중 **법 시행일·수치**에 의존하는 문항을 표로 정리하고, 확인할 공식 출처도 알려줘" |
| 교재와 대조 | "교재 6판 해당 절 사진/텍스트를 붙일게. **교재 서술과 다른 문항**을 찾아서 고쳐줘" |
| 모의고사화 | "450문항 중에서 **90분 모의고사 1세트**를 뽑아 섞고, 과목 배점(15/15/50/20)에 맞게 가중해줘" |

## 4-1. 제미나이 추천 양식 평가와 보완점

제미나이가 추천한 양식(역할 → 작업 목표 → 변형 기준 → 출력 양식 → 원본 자료)은 **뼈대가 좋습니다**. 이번 450문항도 이 양식의 출력 형식(정답 / 핵심 해설 / 원문 대비 변형 포인트)을 그대로 따랐습니다. 다만 아래 4가지를 보완하면 결과가 더 좋아집니다.

| 부족한 점 | 왜 문제인가 | 보완 문구 예시 |
|---|---|---|
| **기준 시점·교재 판수가 없음** | AI가 학습 시점의 오래된 사실로 문제를 만듦 | "교재 6판, 2026년 11월 시행 중인 법·제도 기준" |
| **사실 검증 요구가 없음** | 최신 법령 시행일·수치를 지어낼 위험이 가장 큼 | "확실하지 않은 사실은 [확인 필요]로 표시하고, 원본 정답과 충돌하는 내용은 쓰지 마" |
| **수량·배점·정답 분포가 없음** | 과목 비중이 틀리거나 정답이 ③에 몰림 | "3과목 180문항, 파일당 30문항, 정답 ①~④가 균등하게" |
| **정답이 문제 바로 아래 노출** | 스스로 풀어 보기 불편함 | "정답은 접기(`<details>`)로 숨기고, 파일 끝에 빠른 정답표를 둬" |

또한 "수석 출제위원이야, 완벽하게 이해하고 있어" 같은 **역할 과장은 효과가 작습니다**. 그보다는 **교재 목차와 기출 원문을 직접 붙여넣는 것**이 정확도를 훨씬 크게 올립니다.

## 5. 주의사항

- **최신 법령·시행일·수치는 AI가 틀릴 수 있습니다.** 시험 직전에 교재(6판)와 금융위·개인정보위·한국은행 보도자료로 확인하세요.
- **실제 교재 목차를 함께 첨부하면 정확도가 크게 올라갑니다.** 교재 6판의 목차나 요약을 붙여넣으면 "시험에 나올 범위"를 정확히 맞출 수 있습니다.
- **한 번에 너무 많이 요청하지 마세요.** 과목별로 나눠 요청하면 품질이 안정적입니다.
- **정답을 외우지 말고 "왜 틀렸는지"를 확인하세요.** 최신 시험은 단순 암기보다 긴 지문 속 **숨은 오류 찾기**가 많습니다.
